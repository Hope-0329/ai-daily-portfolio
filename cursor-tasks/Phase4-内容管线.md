# Phase 4: 内容管线

给 Cursor Agent 的自然语言说明：

---

上一轮你的双层过滤引擎把 200+ 篇筛成了 15-25 篇精选。但这些文章现在只有原始标题和摘要，格式很粗糙，英文源还是英文的。这一轮要把它们加工成高可读性的日报内容。

## 四个子模块

```
15-25 篇精选文章
  → 英文翻译（标题 + 摘要翻中文）
  → 文章分类（模型 / 产品 / 行业 / 论文 / 技巧）
  → LLM 生成"一句话读懂"摘要
  → 组装日报（5 板块 + TOP 3 + 选题池 + 碎碎念）
```

## 一、英文翻译

新建 `src/pipeline/translator.py`。

只翻译英文文章（language="en"），中文跳过。翻译两样东西：标题和摘要。

Prompt：
```
你是一个专业的 AI 行业翻译。请把以下英文 AI 新闻标题翻译成中文。

要求：
- 专业术语准确（比如 "fine-tuning" → "微调"，"hallucination" → "幻觉"）
- 保持原文的信息密度，不要删减
- 不要加"据报道""据悉"等废话
- 中文表达自然流畅，读起来像中文写的

英文原文：{text}
中文翻译：
```

实现要点：
- 标题和摘要各调一次 LLM（两条短的，成本低）
- 用 asyncio.gather 把一篇文章的标题翻译和摘要翻译并发
- 多篇文章之间也并发（Semaphore 5，避免打爆 API）
- 翻译结果写入 Article.title_cn 和 Article.summary_cn 字段（如果 models 里没有 summary_cn，就在 Article 上加一个字段）
- LLM 调用失败时，title_cn 留空（不要阻塞流程）

## 二、文章分类

新建 `src/pipeline/classifier.py`。

把每篇文章分到 5 个类别之一：

| 类别 | 含义 | 典型关键词 |
|------|------|-----------|
| ai-models | 模型发布/更新 | 新模型、开源、基准测试、参数、架构、训练 |
| ai-products | 产品发布/更新 | 上线、发布、功能更新、API、SDK、插件 |
| industry | 行业动态 | 融资、收购、政策、监管、财报、竞争、裁员 |
| paper | 论文研究 | arXiv、论文、研究、benchmark、SOTA、ACL/NeurIPS |
| tip | 技巧与观点 | 教程、工具推荐、经验分享、观点、方法论 |

实现策略：**先规则，不确定才走 LLM**。

规则部分：
```python
def rule_classify(title: str, summary: str, source_type: str) -> Optional[Category]:
    # 学术源 + 标题含"paper/论文/SOTA/benchmark" → paper
    # 标题含"发布/上线/推出/更新"+产品类词 → ai-products
    # 标题含"融资/收购/裁员/财报/监管/政策" → industry
    # 标题含"教程/如何/指南/推荐/经验/技巧" → tip
    # 标题含模型名/技术词"模型/LLM/GPT/参数/训练/架构" → ai-models
    # 都不确定 → 返回 None，交 LLM
```

LLM 部分（仅规则不确定的走）：
```
你是一个 AI 新闻分类专家。把以下文章分到 5 个类别之一。
只返回类别名，不要解释。

类别：ai-models / ai-products / industry / paper / tip

标题：{title}
摘要：{summary}

类别：
```

注意：分类时用 title_cn（如果有翻译的话），没有就给原始 title。

## 三、LLM 摘要生成

新建 `src/pipeline/summarizer.py`。

这是跟竞品拉开差距的地方——不是原文截取摘要，而是 LLM 生成"人话摘要"。

Prompt：
```
你是 AI 行业资讯编辑。请用一句话（30-60 字）总结以下新闻的核心信息。

要求：
1. 说人话，有信息量，不要照抄原文句式
2. 包含最关键的 1-2 个数字或事实
3. 不要用"据报道""据悉""近日"等套话
4. 如果是产品发布，说清楚"谁发布了什么、有什么用"
5. 如果是行业动态，说清楚"发生了什么事、对谁有影响"

标题：{title_cn or title}
原文摘要：{summary_raw}
正文片段：{content[:500]}

一句话总结：
```

实现要点：
- 所有精选文章都生成摘要，不管中文还是英文
- 并发调用（Semaphore 5）
- 结果写入 Article.summary
- 失败不阻塞，保留原始 summary_raw

### TOP 3 + 选题池 + 碎碎念 — 都是 LLM 生成

这三块每次日报都要调 LLM：

**TOP 3 选择**：
```
以下是今天 L2 精选的 {N} 篇文章。请选出最重要的 TOP 3，
为每篇写 15-25 字的一句话推荐理由。

{文章列表：编号、标题、来源、评分}

返回 JSON: [{"id": "编号", "reason": "推荐理由"}, ...]
```

**选题池**：
```
基于今天的精选文章，推荐 5 个值得深度写作的选题。
每个选题包含标题、理由、信息来源。

{文章列表}

返回 JSON: [{"title": "选题", "reason": "理由", "sources": ["来源"]}, ...]
```

**碎碎念**：
```
你是 AI 博主"知识侦察兵"。看完今天的 AI 新闻，写 2-3 段个人化的感想。

风格要求：
- 真实、有态度、有洞见
- 像朋友聊天，不官腔
- 可以表达兴奋、质疑、批评
- 把不同新闻联系起来看趋势
- 约 200 字

今天的重要新闻：
{文章标题列表}
```

### 分类排序

每个板块内的文章按评分从高到低排列。

如果某个板块没有文章（比如今天没有论文），那个板块的表格就留空，但板块标题保留，表里写"暂无"。

### YAML frontmatter

日报头的 YAML 要包含：date、generated（ISO 时间戳）、sources（成功/总数）、candidates（L1 通过数）、selected（L2 精选数）、snr（信噪比百分比）、quality_rate（质量率百分比）。
